🚲 Bike Sales Interactive Dashboard
Tool: Microsoft Excel

Overview
This project analyzes demographic data to understand customer purchasing behavior for a fictional bike retail company. I built an interactive dashboard to explore how factors like income, commute distance, and age influence a customer's decision to purchase a bike.

Key Skills Applied
Data Cleaning: Standardized inconsistent text formatting, removed duplicate records, and cleaned numeric/currency data.

Data Transformation: Engineered new categorical variables (e.g., Age Brackets) using Nested IF statements.

Data Modeling & Aggregation: Utilized Pivot Tables to summarize key metrics across various customer segments.

Data Visualization: Designed an interactive dashboard using dynamic charts and Slicers for user-driven exploration.

Business Insights
Age Dynamics: Middle-aged customers (31-54) account for the highest volume of bike purchases compared to adolescent and older demographics.

Income Correlation: Across both genders, individuals who purchased a bike had a higher average income than those who did not.

Commute Impact: Customers with a shorter commute (0-1 miles) are significantly more likely to purchase a bike than those commuting longer distances.
